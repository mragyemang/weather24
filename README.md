# Weather24

A modern weather experience that helps users check the forecast for any city while matching the mood of the weather. From bright and sunny interfaces to calm, moody rainy themes, Weather24 turns everyday weather updates into a more engaging and atmospheric experience.

## Overview

Weather24 is a lightweight weather dashboard designed to make checking the forecast feel more delightful and visually expressive. Instead of a plain weather widget, it presents conditions in a style that reflects the atmosphere outside — warm sunlight, cool rain, clear skies, and everything in between.

Whether users want to quickly see a city’s temperature or enjoy a more immersive mood-driven interface, Weather24 brings useful weather data together with a polished, welcoming design.

## Key Features

- City search for instant weather lookup
- Real-time weather condition display
- Temperature, conditions, and weather status summaries
- Mood-based visual themes
  - Sunny = bright, warm, uplifting
  - Rainy = calm, cool, atmospheric
  - Cloudy = soft and neutral
- Responsive and clean user interface
- Fast, simple browsing experience
- Designed for modern web usage

## Why Weather24?

Most weather apps focus purely on data. Weather24 focuses on experience.

It blends practical information with emotional design so that the interface feels aligned with the current weather. A sunny day feels joyful, while a rainy day feels calm and reflective — giving the user a richer, more memorable weather-checking experience.

## Project Goals

- Make weather information easier to read and enjoy
- Create a more expressive, mood-aware interface
- Support quick city lookups with a clean design
- Deliver a highly usable, polished weather dashboard

## How It Works

1. A user enters a city name.
2. The app fetches the relevant weather data.
3. The interface updates with the current atmospheric conditions.
4. The visual theme shifts to match the mood of the weather.
5. Results are displayed in a clean, accessible, and user-friendly layout.

## Getting Started

### Prerequisites

Before running the app, make sure you have:

- A modern web browser
- Node.js and npm installed (if applicable)
- Access to a weather data API key

### Installation

```bash
git clone https://github.com/mragyemang/weather24.git
cd weather24
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local development URL in your browser.

## Environment Variables

If the app uses a weather API, create a `.env` file in the project root and add your configuration:

```env
VITE_WEATHER_API_KEY=your_api_key_here
```

Adjust the variable names to match your project setup.
